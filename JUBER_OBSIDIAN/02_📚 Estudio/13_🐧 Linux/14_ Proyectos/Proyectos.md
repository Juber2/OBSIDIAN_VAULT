# Proyectos Linux

## Proposito del capitulo

Este capitulo aplica todo el libro en cinco proyectos progresivos, cada uno construido sobre el anterior: configurar un servidor web completo, automatizar backups, hardening de seguridad, monitoreo con alertas, y un proyecto final que integra infraestructura como codigo con containers Docker.

**Nivel esperado:** Mid a Senior.

## Como usar este capitulo

1. Cada proyecto se construye sobre el servidor del anterior, no desde cero.
2. Se aplica la checklist tecnica de cada proyecto antes de darlo por completo.
3. Se documentan decisiones no obvias con ADRs a medida que se avanza, no al final.
4. El proyecto final integra infraestructura como codigo con containers Docker, conectando ambos libros.

## Como cerrar este capitulo

- [ ] Complete los cinco proyectos en orden, cada uno construido sobre el anterior.
- [ ] Cada proyecto tiene su checklist tecnica verificada, no solo "funciona".
- [ ] El proyecto final es completamente reproducible desde cero via Ansible.
- [ ] Tengo al menos dos ADRs reales escritos a lo largo de los proyectos.

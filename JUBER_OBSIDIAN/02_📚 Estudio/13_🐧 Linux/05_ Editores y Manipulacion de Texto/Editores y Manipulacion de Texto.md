# Editores y Manipulacion de Texto

## Proposito del capitulo

Este capitulo cubre las herramientas de texto que definen la productividad de un administrador Linux: Vim para edicion rapida, sed para transformaciones automatizadas, awk para procesamiento de datos columnares, grep avanzado para busqueda, y la combinacion de todas ellas en pipelines complejos.

**Nivel esperado:** Junior a Mid.

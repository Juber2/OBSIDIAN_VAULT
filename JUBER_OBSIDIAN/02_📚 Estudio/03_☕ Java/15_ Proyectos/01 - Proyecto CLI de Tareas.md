# Proyecto CLI de Tareas

## Objetivo

Crear una aplicacion de consola para gestionar tareas.

## Requisitos

- Crear tarea.
- Listar tareas.
- Marcar como completada.
- Eliminar tarea.
- Guardar en archivo JSON o texto.

## Practicas

- Clases y objetos.
- Colecciones.
- Manejo de excepciones.
- Separacion entre UI de consola y logica.

## Checklist

- [ ] El codigo compila desde terminal.
- [ ] Hay tests unitarios para la logica.
- [ ] Los errores se muestran de forma clara.
- [ ] El README explica como ejecutar.

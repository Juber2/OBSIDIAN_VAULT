# Proyecto Java Senior Final

## Objetivo

Crear una plataforma backend completa con calidad de portafolio senior.

## Debe incluir

- Arquitectura limpia o hexagonal.
- Spring Boot.
- PostgreSQL con Flyway.
- Seguridad con JWT/OAuth2.
- Cache con Redis o Caffeine.
- Mensajeria.
- Tests unitarios, integracion y contractuales si aplica.
- Docker Compose.
- Observabilidad con logs, metricas y traces.
- CI/CD.
- ADRs.

## Entregables

- README profesional.
- Diagrama de arquitectura.
- Coleccion Postman/HTTP.
- Evidencia de tests.
- Retrospectiva tecnica.

## Checklist

- [ ] El proyecto arranca con un comando.
- [ ] Tiene datos de prueba.
- [ ] Tiene cobertura de casos criticos.
- [ ] Explica tradeoffs.
- [ ] Se puede mostrar en entrevista.

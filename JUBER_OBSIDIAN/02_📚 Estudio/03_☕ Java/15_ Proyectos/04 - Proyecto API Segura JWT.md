# Proyecto API Segura JWT

## Objetivo

Construir autenticacion y autorizacion con Spring Security.

## Requisitos

- Registro.
- Login.
- JWT firmado.
- Refresh token si deseas subir dificultad.
- Roles.
- Permisos por recurso.
- Tests de seguridad.

## Checklist

- [ ] Passwords hasheados con BCrypt/Argon2.
- [ ] JWT tiene expiracion.
- [ ] Endpoints privados rechazan usuarios anonimos.
- [ ] Usuarios no acceden recursos ajenos.
- [ ] No se loguean tokens.

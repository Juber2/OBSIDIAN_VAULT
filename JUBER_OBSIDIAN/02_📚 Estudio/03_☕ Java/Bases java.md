# Bases java

Nota base para conceptos generales del ecosistema Java.

## Conceptos clave

| Concepto | Resumen |
|---|---|
| JDK | Kit de desarrollo: compilador, herramientas y runtime |
| JRE | Runtime para ejecutar aplicaciones Java |
| JVM | Maquina virtual que ejecuta bytecode |
| Bytecode | Resultado de compilar `.java` a `.class` |
| Classpath | Ruta donde Java busca clases y dependencias |
| Build tool | Herramienta como Maven o Gradle para compilar y gestionar dependencias |

## Indicadores de senioridad

- [ ] Encuentro riesgos antes de que lleguen a produccion.
- [ ] Simplifico soluciones sin empobrecer el diseno.
- [ ] Puedo guiar a otros sin hacer todo por ellos.
- [ ] Tomo decisiones tecnicas con contexto de negocio.
- [ ] Escribo codigo que otros pueden mantener.

## Ruta recomendada

1. Aprende bien Java puro antes de Spring.
2. Practica testing desde temprano, no al final.
3. Entra a Spring Boot despues de entender IoC, DI, HTTP y bases de datos.
4. Estudia arquitectura cuando ya puedas construir una API CRUD sin mirar tutorial.
5. Cierra cada bloque con un proyecto pequeno.

## Checkpoint senior

- [ ] Puedo explicar JVM, heap, stack, GC y classpath/module-path.
- [ ] Puedo modelar dominio con clases, records, enums, value objects y excepciones propias.
- [ ] Puedo crear APIs REST limpias con validacion, errores consistentes y pruebas.
- [ ] Puedo usar JPA sin caer en N+1, transacciones mal ubicadas o entidades anemicas.
- [ ] Puedo asegurar una API con JWT/OAuth2, roles y permisos.
- [ ] Puedo dockerizar, observar, medir y diagnosticar una app Java.
- [ ] Puedo disenar servicios mantenibles con Clean Architecture, Hexagonal o DDD ligero.
- [ ] Puedo revisar codigo de otros y detectar riesgos de performance, seguridad y mantenibilidad.

# Arquitectura NestJS

## Proposito del capitulo

Este capitulo cubre arquitectura de software aplicada a NestJS, de menor a mayor complejidad: separacion de capas basica, Domain Driven Design, CQRS, monolito modular, Clean Architecture/Hexagonal, y cuando (y como) migrar a microservicios. Es el capitulo que define si un proyecto Nest sigue siendo mantenible a medida que crece.

**Nivel esperado:** Senior.

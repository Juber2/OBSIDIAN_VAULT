# Libro NestJS Junior a Senior

Esta carpeta no es solo una ruta. Esta pensada como un **libro de estudio practico** para avanzar desde bases de Node.js/TypeScript hasta criterio senior de backend con NestJS.

La estructura esta dividida en capitulos. Cada capitulo contiene explicacion, modelo mental, ejemplos, errores comunes, practica, preguntas de repaso y criterios junior/mid/senior.

## Como usar este libro

1. Lee el capitulo en orden.
2. Ejecuta al menos un ejemplo en un proyecto NestJS real de practica.
3. Convierte cada tema importante en un mini commit.
4. Agrega tests cuando el tema toque HTTP, base de datos, auth, colas o reglas de negocio.
5. Vuelve a cada nota y marca el checklist solo cuando puedas explicarlo sin mirar tutorial.

## Resultado esperado

Al terminar, deberias poder construir y mantener una aplicacion NestJS real: API REST u opcionalmente GraphQL, auth con JWT y autorizacion granular, persistencia con TypeORM o Prisma, testing completo (unitario y e2e), procesamiento en background y tiempo real, arquitectura escalable, y despliegue en produccion con CI/CD y observabilidad.

## Checkpoint senior

- [ ] Puedo construir APIs NestJS mantenibles, testeadas y seguras, con capas bien separadas.
- [ ] Domino TypeORM/Prisma sin caer en N+1, transacciones mal manejadas ni migrations improvisadas.
- [ ] Puedo diseñar autenticacion JWT con refresh tokens, RBAC y autorizacion condicional (CASL).
- [ ] Puedo usar colas (BullMQ), eventos de dominio, WebSockets y microservicios cuando el problema real lo justifica.
- [ ] Puedo decidir entre monolito modular, DDD, CQRS, arquitectura hexagonal o microservicios segun el contexto, no por moda.
- [ ] Puedo desplegar NestJS con Docker, CI/CD, observabilidad y una estrategia de performance basada en datos medidos.
- [ ] Puedo revisar codigo NestJS detectando riesgos de seguridad, performance y mantenibilidad, y liderar esas decisiones en equipo.

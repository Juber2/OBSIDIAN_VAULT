# NestJS Core

## Proposito del capitulo

NestJS Core es el conjunto de piezas que vas a usar todos los dias: modulos, controllers, providers/DI, pipes, guards, interceptors, middleware y decoradores personalizados. Dominar esto evita controllers gigantes y aplicaciones dificiles de mantener.

**Nivel esperado:** Junior a Mid.

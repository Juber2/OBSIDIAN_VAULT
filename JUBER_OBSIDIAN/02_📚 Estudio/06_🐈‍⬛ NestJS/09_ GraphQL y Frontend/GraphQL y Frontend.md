# GraphQL y Frontend

## Proposito del capitulo

Este capitulo cubre las formas en que NestJS se conecta con clientes frontend: GraphQL con resolvers, la eleccion entre schema first y code first, generacion de clientes tipados a partir de OpenAPI, integracion practica con Angular, y manejo de archivos (upload/streaming).

# TypeORM Prisma y Base de Datos

## Proposito del capitulo

Este capitulo cubre el acceso a datos en NestJS: configuracion de conexion, entidades y repositorios con TypeORM, relaciones y el problema de N+1, migrations y seeders, Prisma como alternativa, y transacciones/concurrencia. Es la base de cualquier API que persista datos de forma seria.

**Nivel esperado:** Junior a Mid.

# Fundamentos Node y TypeScript

## Proposito del capitulo

Antes de escribir codigo Nest en serio hay que dominar el terreno sobre el que corre: Node.js (event loop, modulos), TypeScript moderno (decoradores, tipos) y las herramientas basicas del ecosistema (npm/pnpm, Nest CLI). Sin esta base, los errores de DI, de tipado o de performance se vuelven dificiles de diagnosticar.

**Nivel esperado:** Junior.

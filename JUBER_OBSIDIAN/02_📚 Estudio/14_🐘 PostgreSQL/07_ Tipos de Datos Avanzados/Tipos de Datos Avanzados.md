# Tipos de Datos Avanzados

## Proposito del capitulo

Este capitulo cubre los tipos de datos que hacen a Postgres "objeto-relacional": JSON/JSONB para datos semi-estructurados, arrays nativos, tipos geometricos y PostGIS para geolocalizacion, Full Text Search nativo, y ENUM/dominios/tipos compuestos custom.

**Nivel esperado:** Mid a Senior.

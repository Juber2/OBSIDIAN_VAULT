# SQL Fundamentals en Postgres

## Proposito del capitulo

Este capitulo cubre el SQL fundamental que se usa todos los dias en Postgres: creacion de tablas y tipos de datos, modificacion de datos (INSERT/UPDATE/DELETE), lectura y filtrado con SELECT, JOINs de todos los tipos, y agregacion con GROUP BY/HAVING.

**Nivel esperado:** Junior.

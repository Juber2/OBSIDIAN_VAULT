# Proyectos PostgreSQL

## Proposito del capitulo

Este capitulo aplica todo el libro en cinco proyectos progresivos: diseñar un esquema completo normalizado, optimizar queries con evidencia medida, configurar replicacion basica, integrar todo con una API NestJS real, y un proyecto final production-ready.

**Nivel esperado:** Mid a Senior.

## Como usar este capitulo

1. Cada proyecto se construye sobre el anterior, no desde cero.
2. Se aplica la checklist tecnica de cada proyecto antes de darlo por completo.
3. Se documentan decisiones no obvias con ADRs a medida que se avanza.
4. El proyecto final integra administracion, alta disponibilidad, performance y seguridad sobre todo lo construido antes.

## Como cerrar este capitulo

- [ ] Complete los cinco proyectos en orden, cada uno construido sobre el anterior.
- [ ] Cada proyecto tiene su checklist tecnica verificada, no solo "funciona".
- [ ] El proyecto final tiene backups probados y roles de permisos minimos.
- [ ] Tengo al menos dos ADRs reales escritos a lo largo de los proyectos.

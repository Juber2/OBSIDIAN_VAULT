# ChatGPT y Codex — manual de herramientas para programación

Esta ruta responde a una pregunta concreta: **¿qué herramientas incluye el ecosistema ChatGPT/Codex y cómo combinarlas para aprovecharlas al máximo al programar?**

No es otro curso genérico de IA. El prompting queda en un solo capítulo; el resto está organizado por producto, herramienta y capacidad real.

## Selección rápida

| Si necesitas... | Usa primero... |
|---|---|
| Una explicación o decisión técnica | Chat |
| Convertir archivos/datos en un resultado revisable | Work + archivos |
| Mantener contexto de un producto durante semanas | Project |
| Información reciente y puntual | Web search |
| Investigación extensa y contrastada | Research/long-running work |
| Editar un repositorio y ejecutar tests | Codex Desktop/CLI/IDE |
| Delegar varias tareas aisladas | Codex cloud |
| Probar una interfaz como usuario | Browser/computer use |
| Crear un prototipo web publicable | Sites |
| Repetir un procedimiento | Skill o tarea programada |
| Conectar GitHub, Slack, Figma u otro sistema | Plugin/app/MCP |

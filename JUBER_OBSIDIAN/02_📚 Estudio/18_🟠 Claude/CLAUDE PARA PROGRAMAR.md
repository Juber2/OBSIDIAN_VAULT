# Claude y Claude Code — manual de herramientas para programación

Esta ruta explica **qué herramientas tiene Claude, qué cambia entre Claude chat, Projects, Artifacts, Cowork y Claude Code, y cómo combinarlas para programar mejor**.

El prompting ocupa un capítulo final. El núcleo es producto, capacidades, configuración, permisos, extensiones y recetas de uso.

> Revisado el 2026-08-24. Modelos, planes, límites y funciones cambian. Confirma disponibilidad en las referencias oficiales de cada nota.

# Docker para Diferentes Stacks

## Proposito del capitulo

Este capitulo aplica todo el libro a stacks tecnologicos reales: dockerizar una API NestJS, una app .NET, un frontend Angular, bases de datos para desarrollo, y como integrarlos todos en un stack full-stack completo con Compose. Conecta directamente con el [[NESTJS|libro de NestJS]] y con proyectos .NET como StaffTrainingPlatform.

**Nivel esperado:** Mid a Senior.

## Como cerrar este capitulo

- [ ] Lei cada tema como capitulo, no solo como checklist.
- [ ] Dockericé al menos un backend real (NestJS o .NET) con multi-stage build.
- [ ] Dockericé un frontend Angular sirviendo con Nginx correctamente.
- [ ] Integré todo en un stack full-stack completo levantable con un unico comando.
- [ ] Tengo notas propias de dudas, decisiones o patrones que quiero repetir.

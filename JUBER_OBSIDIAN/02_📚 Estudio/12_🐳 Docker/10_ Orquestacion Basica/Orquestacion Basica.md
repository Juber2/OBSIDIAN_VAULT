# Orquestacion Basica

## Proposito del capitulo

Este capitulo cubre orquestacion de containers mas alla de un unico servidor: Docker Swarm como orquestador nativo simple, una introduccion conceptual a Kubernetes desde la perspectiva de Docker, y el criterio para decidir cuando (y si) migrar de Compose a un orquestador real.

**Nivel esperado:** Mid a Senior.

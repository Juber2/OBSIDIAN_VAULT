## Proposito del capitulo

Este capitulo aplica todo el libro en cinco proyectos progresivos, cada uno construido sobre el anterior: dockerizar una API con multi-stage, un stack completo con Compose, un pipeline de CI/CD, hardening de seguridad, y un proyecto final llevado a estado production-ready.

## Como usar este capitulo

1. Cada proyecto se construye sobre el codigo del anterior, no desde cero.
2. Se aplica la checklist tecnica de cada proyecto antes de darlo por completo.
3. Se documentan decisiones no obvias con ADRs a medida que se avanza, no al final.
4. El proyecto final integra CI/CD, seguridad, observabilidad y criterio senior sobre todo lo construido antes.

## Como cerrar este capitulo

- [ ] Complete los cinco proyectos en orden, cada uno construido sobre el anterior.
- [ ] Cada proyecto tiene su checklist tecnica verificada, no solo "funciona".
- [ ] El proyecto final esta hardened, con CI/CD y documentacion completa.
- [ ] Tengo al menos dos ADRs reales escritos a lo largo de los proyectos.

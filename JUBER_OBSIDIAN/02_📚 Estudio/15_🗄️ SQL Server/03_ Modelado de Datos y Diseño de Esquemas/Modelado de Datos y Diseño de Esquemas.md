## Proposito del capitulo

Este capitulo cubre el diseño de esquemas relacionales en T-SQL, aplicando la teoria ya dominada en Postgres: normalizacion, claves primarias y foraneas, constraints, los tres tipos de relaciones, y diseño especifico para aplicaciones .NET con Entity Framework Core.

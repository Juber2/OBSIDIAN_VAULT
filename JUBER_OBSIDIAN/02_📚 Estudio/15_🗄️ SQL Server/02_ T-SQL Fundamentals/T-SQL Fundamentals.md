# T-SQL Fundamentals

## Proposito del capitulo

Este capitulo cubre el T-SQL fundamental que se usa todos los dias: creacion de tablas y tipos de datos, modificacion de datos con OUTPUT, lectura y filtrado con particularidades de collation, JOINs (identicos a Postgres en logica), y agregacion con GROUPING SETS.

**Nivel esperado:** Junior.

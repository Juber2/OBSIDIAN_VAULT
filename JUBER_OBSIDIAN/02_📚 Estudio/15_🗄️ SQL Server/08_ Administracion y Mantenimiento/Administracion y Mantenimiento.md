Este capitulo cubre administracion operativa de SQL Server: backups Full/Differential/Log, Recovery Models y restauracion con PITR, el modelo de seguridad Login/User con GRANT/DENY, mantenimiento de indices fragmentados, y automatizacion con SQL Server Agent.

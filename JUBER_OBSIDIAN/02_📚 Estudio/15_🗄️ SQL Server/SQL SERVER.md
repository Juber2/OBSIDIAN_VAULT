# SQL Server — Roadmap Junior a Senior

## Proposito

Libro completo de SQL Server, de fundamentos a nivel senior, en 14 capitulos. Diseñado como el par directo del libro de [[POSTGRESQL]]: mismos conceptos fundamentales de bases de datos relacionales, mismo formato y profundidad, con foco constante en las diferencias tecnicas reales entre ambos motores y en la integracion profunda con el ecosistema .NET/EF Core (StaffTrainingPlatform como referencia constante).

**Nivel esperado del libro completo:** Junior a Senior.

## Como usar este libro

- Segui el orden de capitulos: cada uno construye sobre el anterior.
- Cada tema individual sigue la estructura: Que vas a aprender / Explicacion / Modelo mental / Ejemplo base / Como se usa en un proyecto real / Criterio junior-mid-senior / Errores comunes / Practica / Preguntas de repaso.
- Los capitulos 8-13 cruzan constantemente con [[POSTGRESQL]] para reforzar transferencia de conocimiento entre motores.
- El capitulo 11 y el capitulo 14 (proyecto 4) conectan directamente con StaffTrainingPlatform, el proyecto .NET + SQL Server real de referencia.
- El capitulo 14 es el cierre practico: no avances a el sin haber completado al menos los capitulos 1-11.

# Proyecto Repo Enterprise

## Objetivo

Configurar un repositorio con prácticas de equipo.

## Debe incluir

- Branch protection.
- PR template.
- Issue templates.
- CODEOWNERS opcional.
- GitHub Actions.
- Dependabot.
- README profesional.
- Release workflow.

## Checklist

- [ ] Main protegida.
- [ ] Checks requeridos.
- [ ] PR template.
- [ ] Dependabot activo.
- [ ] Documentación de contribución.

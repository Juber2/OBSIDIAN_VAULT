## Ruta recomendada

1. Aprende repositorio, working tree, staging area y commits.
2. Practica flujo diario: status, add, commit, log, diff, restore.
3. Domina branches, merge, rebase y conflictos.
4. Usa GitHub con remotes, issues, PRs y reviews.
5. Aprende CI/CD con GitHub Actions.
6. Cierra con estrategias de equipo, seguridad y recuperación de errores.

## Checkpoint senior

- [ ] Puedo explicar working tree, staging area, commit, branch y remote.
- [ ] Puedo resolver conflictos sin pánico.
- [ ] Puedo revisar PRs con criterio técnico.
- [ ] Puedo recuperar trabajo con reflog, reset/revert/cherry-pick.
- [ ] Puedo diseñar una estrategia de ramas para un equipo.
- [ ] Puedo configurar GitHub Actions básico.
- [ ] Puedo proteger ramas, manejar secrets y revisar seguridad.

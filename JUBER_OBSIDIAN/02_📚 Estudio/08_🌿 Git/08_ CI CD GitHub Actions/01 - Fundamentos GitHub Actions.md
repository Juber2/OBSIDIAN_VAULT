# Fundamentos GitHub Actions

GitHub Actions automatiza tareas como build, tests, lint, análisis y despliegues.

## Conceptos

| Concepto | Significado |
|---|---|
| Workflow | automatización definida en YAML |
| Event | disparador: push, PR, schedule |
| Job | grupo de steps |
| Step | comando o action |
| Runner | máquina que ejecuta |

## Checklist

- [ ] Sé dónde van los workflows.
- [ ] Entiendo eventos.
- [ ] Entiendo jobs y steps.
- [ ] Sé leer logs.

# Issues, Labels, Milestones y Projects

Issues ayudan a organizar trabajo.

## Uso

| Herramienta | Uso |
|---|---|
| Issue | tarea, bug o mejora |
| Label | clasificar |
| Milestone | agrupar por versión/objetivo |
| Project | tablero de seguimiento |

## Checklist

- [ ] Issues tienen descripción clara.
- [ ] Labels útiles.
- [ ] Milestones para objetivos.
- [ ] Projects para visualizar flujo.

# Repos Públicos, Privados y README

Un README explica propósito, instalación, uso y comandos principales.

## README mínimo

```md
# Nombre del proyecto

## Requisitos
## Instalación
## Ejecución
## Tests
## Variables de entorno
```

## Repos

- Público: visible para todos.
- Privado: solo colaboradores.

## Checklist

- [ ] README dice cómo ejecutar.
- [ ] Variables documentadas.
- [ ] Licencia si aplica.
- [ ] Repo privado si hay código sensible.

# Markdown para GitHub

GitHub usa Markdown en README, issues y PRs.

```md
## Tareas

- [ ] Crear endpoint
- [ ] Agregar tests

```bash
npm test
```
```

## Checklist

- [ ] Uso títulos claros.
- [ ] Uso checklists.
- [ ] Agrego bloques de código.
- [ ] Linkeo issues/PRs relacionados.

# Qué es GitHub

GitHub es una plataforma para alojar repositorios Git y colaborar con issues, pull requests, code review, actions y paquetes.

## Piezas

- Repositories.
- Issues.
- Pull Requests.
- Actions.
- Releases.
- Projects.
- Wiki.

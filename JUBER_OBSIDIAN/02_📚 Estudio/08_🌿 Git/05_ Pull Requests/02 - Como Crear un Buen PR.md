# Cómo Crear un Buen PR

Un buen PR es pequeño, claro y revisable.

## Debe incluir

- Qué cambia.
- Por qué cambia.
- Cómo probar.
- Capturas si hay UI.
- Riesgos o decisiones.

```md
## Resumen
## Cómo probar
## Notas
```

## Checklist

- [ ] PR pequeño.
- [ ] Descripción clara.
- [ ] Tests o explicación.
- [ ] Sin archivos accidentales.

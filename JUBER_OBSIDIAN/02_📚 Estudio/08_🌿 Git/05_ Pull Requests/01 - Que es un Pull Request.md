# Qué es un Pull Request

Un PR propone cambios de una rama hacia otra. Permite revisión, discusión, CI y aprobación antes de merge.

## Contiene

- Commits.
- Diff.
- Descripción.
- Checks.
- Comentarios.
- Reviews.

## Checklist

- [ ] Entiendo rama origen y destino.
- [ ] Reviso diff antes de abrir.
- [ ] Espero checks.
- [ ] Pido review.

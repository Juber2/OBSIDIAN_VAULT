# PR Templates

Templates estandarizan información de PR.

```md
## Resumen

## Tipo de cambio
- [ ] Bugfix
- [ ] Feature
- [ ] Refactor

## Cómo probar

## Checklist
- [ ] Tests actualizados
- [ ] Documentación actualizada
```

## Checklist

- [ ] Template pide contexto útil.
- [ ] No es demasiado largo.
- [ ] Incluye cómo probar.
- [ ] Incluye riesgos si aplica.

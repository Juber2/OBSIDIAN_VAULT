# Code Review en GitHub

Review busca reducir riesgos y mejorar calidad.

## Revisar

- Correctitud.
- Tests.
- Seguridad.
- Performance.
- Mantenibilidad.
- Claridad del cambio.

## Buen comentario

```text
Este método parece mezclar validación y persistencia. ¿Podemos mover la validación al caso de uso para testearla aislada?
```

## Checklist

- [ ] Priorizo bugs sobre gustos.
- [ ] Dejo comentarios accionables.
- [ ] Marco bloqueantes con claridad.
- [ ] Apruebo si el riesgo es aceptable.

# Recuperación ante Incidentes Git

Incidentes comunes: reset accidental, force push, merge incorrecto, secretos subidos.

## Secuencia

1. Pausar.
2. Revisar reflog/log.
3. Crear rama de respaldo.
4. Recuperar cambios.
5. Comunicar al equipo.
6. Documentar prevención.

## Checklist

- [ ] No entro en pánico.
- [ ] Creo backup branch.
- [ ] Uso reflog.
- [ ] Coordino antes de force push.

# Higiene de Historial

Historial limpio ayuda a debug, reviews y auditoría.

## Reglas

- Commits con intención.
- No subir basura temporal.
- Squash de WIP si aplica.
- Tags para releases.
- Changelog cuando el proyecto lo necesita.

## Checklist

- [ ] Commits coherentes.
- [ ] PRs pequeños.
- [ ] Releases trazables.
- [ ] Sin secretos ni archivos generados.

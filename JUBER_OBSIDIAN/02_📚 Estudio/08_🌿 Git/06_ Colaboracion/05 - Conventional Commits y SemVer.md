# Conventional Commits y SemVer

Conventional Commits estandariza mensajes.

```text
feat: add login form
fix: handle expired token
docs: update README
refactor: simplify user service
```

## SemVer

```text
MAJOR.MINOR.PATCH
```

## Checklist

- [ ] Uso tipos consistentes.
- [ ] Mensaje describe intención.
- [ ] Breaking changes claros.
- [ ] Versionado coherente.

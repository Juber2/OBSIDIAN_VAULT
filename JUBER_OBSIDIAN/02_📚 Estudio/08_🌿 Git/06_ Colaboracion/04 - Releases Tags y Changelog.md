# Releases, Tags y Changelog

Tags marcan versiones. Releases publican una versión con notas.

```bash
git tag v1.0.0
git push origin v1.0.0
```

## Changelog

Debe explicar cambios relevantes para usuarios/devs.

## Checklist

- [ ] Uso tags para versiones.
- [ ] Release notes claras.
- [ ] Changelog actualizado.
- [ ] SemVer si aplica.

# Organizaciones, Teams y Permisos

GitHub permite organizar personas y accesos.

## Permisos comunes

| Permiso | Uso |
|---|---|
| Read | leer |
| Triage | manejar issues/PRs |
| Write | push y colaborar |
| Maintain | administrar sin owner |
| Admin | control completo |

## Checklist

- [ ] Principio de menor privilegio.
- [ ] Teams por rol/proyecto.
- [ ] Owners limitados.
- [ ] Accesos revisados periódicamente.

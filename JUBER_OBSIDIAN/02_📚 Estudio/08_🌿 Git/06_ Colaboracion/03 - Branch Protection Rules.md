# Branch Protection Rules

Protegen ramas importantes como `main`.

## Reglas útiles

- Require pull request.
- Require approvals.
- Require status checks.
- Require conversation resolution.
- Restrict force pushes.

## Checklist

- [ ] Main protegida.
- [ ] Checks obligatorios.
- [ ] Reviews requeridos.
- [ ] Force push bloqueado.

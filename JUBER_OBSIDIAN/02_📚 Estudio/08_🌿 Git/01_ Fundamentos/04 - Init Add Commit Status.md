# Init, Add, Commit y Status

Comandos base para crear historial.

```bash
git init
git status
git add README.md
git commit -m "Add README"
```

## Buen commit

Un buen commit es pequeño, coherente y explica intención.

```bash
git commit -m "Add product validation"
```

## Checklist

- [ ] Creo repos con `git init`.
- [ ] Reviso `git status` antes de commitear.
- [ ] Agrego solo cambios relacionados.
- [ ] Escribo mensajes claros.

# Log, Diff y Show

Estos comandos ayudan a inspeccionar cambios e historial.

```bash
git log --oneline --graph --decorate
git diff
git diff --staged
git show HEAD
```

## Uso

| Comando | Uso |
|---|---|
| `git log` | ver commits |
| `git diff` | ver cambios no staged |
| `git diff --staged` | ver cambios staged |
| `git show` | inspeccionar commit |

## Checklist

- [ ] Reviso diff antes de commit.
- [ ] Entiendo historial básico.
- [ ] Uso `--oneline --graph`.
- [ ] Sé inspeccionar un commit.

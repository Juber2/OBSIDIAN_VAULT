# Qué es Git

Git es un sistema de control de versiones distribuido. Sirve para registrar cambios, volver atrás, trabajar en ramas y colaborar con otras personas.

## Qué resuelve

- Historial de cambios.
- Comparar versiones.
- Trabajar en paralelo.
- Recuperar cambios.
- Colaborar en equipo.

## Git vs GitHub

| Herramienta | Qué es |
|---|---|
| Git | herramienta local de versionado |
| GitHub | plataforma para alojar repos, PRs, issues y CI/CD |

## Checklist

- [ ] Entiendo que Git funciona localmente.
- [ ] Entiendo que GitHub es una plataforma remota.
- [ ] Sé por qué un commit debe ser pequeño y claro.
- [ ] Sé que Git guarda snapshots, no solo archivos sueltos.

# Repositorio, Working Tree, Staging y Commit

Git separa tus cambios en zonas.

| Zona | Significado |
|---|---|
| Working tree | archivos modificados en tu carpeta |
| Staging area | cambios preparados para commit |
| Repository | historial guardado |
| Commit | snapshot confirmado |

```text
working tree -> git add -> staging -> git commit -> repository
```

## Checklist

- [ ] Entiendo qué está modificado.
- [ ] Entiendo qué está en staging.
- [ ] Sé que commit guarda lo preparado.
- [ ] No hago commit sin revisar.

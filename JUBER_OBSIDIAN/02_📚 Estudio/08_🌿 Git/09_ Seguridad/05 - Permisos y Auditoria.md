# Permisos y Auditoría

La seguridad de GitHub también depende de permisos correctos.

## Buenas prácticas

- Menor privilegio.
- Revisar colaboradores.
- Proteger main.
- Requerir reviews.
- Auditar tokens y apps instaladas.

## Checklist

- [ ] Colaboradores revisados.
- [ ] Apps autorizadas revisadas.
- [ ] Ramas protegidas.
- [ ] Admin limitado.

# Dependabot y Vulnerabilidades

Dependabot detecta dependencias vulnerables y puede abrir PRs de actualización.

## Qué revisar

- Severidad.
- Paquete afectado.
- Versión corregida.
- Breaking changes.
- Tests.

## Checklist

- [ ] Dependabot alerts habilitado.
- [ ] PRs revisados.
- [ ] Tests corren en updates.
- [ ] Vulnerabilidades críticas priorizadas.

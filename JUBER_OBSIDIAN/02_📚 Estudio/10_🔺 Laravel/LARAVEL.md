# Libro Laravel Junior a Senior

Esta carpeta no es solo una ruta. Esta pensada como un **libro de estudio practico** para avanzar desde bases de PHP/Laravel hasta criterio senior de backend.

La estructura esta dividida en capitulos. Cada capitulo contiene explicacion, modelo mental, ejemplos, errores comunes, practica, preguntas de repaso y criterios junior/mid/senior.

## Como usar este libro

1. Lee el capitulo en orden.
2. Ejecuta al menos un ejemplo en un proyecto Laravel.
3. Convierte cada tema importante en un mini commit.
4. Agrega tests cuando el tema toque HTTP, base de datos, auth, jobs o reglas de negocio.
5. Vuelve a cada nota y marca el checklist solo cuando puedas explicarlo sin mirar tutorial.

## Resultado esperado

Al terminar, deberias poder construir y mantener una aplicacion Laravel real: API, auth, autorizacion, Eloquent, testing, queues, deploy, performance, arquitectura y criterios de seniority.

## Checkpoint senior

- [ ] Puedo construir APIs Laravel mantenibles, testeadas y seguras.
- [ ] Domino Eloquent sin caer en N+1, modelos gigantes ni queries ineficientes.
- [ ] Puedo disenar autenticacion, autorizacion, rate limiting y manejo de tokens.
- [ ] Puedo usar queues, eventos, notifications y scheduler en produccion.
- [ ] Puedo desplegar Laravel con Docker, CI/CD, workers, logs y monitoreo.
- [ ] Puedo decidir entre CRUD simple, service layer, modular monolith o arquitectura hexagonal.
- [ ] Puedo revisar codigo Laravel detectando riesgos de seguridad, performance y mantenibilidad.

# Mapa de niveles Angular

## Nivel 0 - Base

HTML, CSS, JavaScript, TypeScript, HTTP, NPM y terminal.

## Nivel 1 - Angular básico

Componentes, templates, binding, control flow, pipes y servicios simples.

## Nivel 2 - Intermedio

DI, routing, guards, forms, HttpClient, interceptors y arquitectura por features.

## Nivel 3 - Avanzado

RxJS, signals, state management, performance y SSR/hydration.

## Nivel 4 - Senior

Testing strategy, seguridad, boundaries, Nx, microfrontends, code review y decisiones técnicas.

## Errores comunes

- Creer que senior significa saber más APIs y no tomar mejores decisiones

## Ampliación práctica

En **Mapa de niveles Angular**, la idea es llevar la nota más allá de una definición. Úsala para responder tres preguntas: qué problema resuelve, cómo se ve en código real y qué error debes evitar en un proyecto empresarial.

## Criterio de uso

No adoptes una técnica solo porque es moderna. Primero identifica el problema: estado difícil, render lento, formulario complejo, rutas desordenadas, permisos confusos o deuda legacy. Luego elige la herramienta Angular que reduzca ese problema con el menor costo razonable.

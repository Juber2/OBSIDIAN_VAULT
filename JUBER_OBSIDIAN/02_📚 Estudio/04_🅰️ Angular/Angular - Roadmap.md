## Ruta recomendada

1. Requisitos previos: web, JavaScript, HTTP, NPM y terminal.
2. TypeScript, convenciones y CLI.
3. Componentes, templates y control flow moderno.
4. Servicios, DI, HTTP, routing y forms.
5. RxJS, Signals, state management y arquitectura.
6. Performance, SSR/hydration, seguridad y testing.
7. Ecosistema, escala, code review y proyecto final.

## Checkpoint senior

- [ ] Construyo una SPA Angular moderna con standalone components.
- [ ] Uso control flow moderno, typed forms, HttpClient, guards e interceptors.
- [ ] Elijo entre Signals, RxJS, servicios y NgRx con criterio.
- [ ] Diseño features con boundaries, data-access, UI y pages.
- [ ] Optimizo con lazy loading, @defer, OnPush/zoneless y budgets.
- [ ] Implemento auth frontend sin olvidar que backend valida permisos.
- [ ] Testeo componentes, servicios, HTTP, guards y flujos críticos.

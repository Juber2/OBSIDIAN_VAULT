# Checklist Profesional dotNET

## API

Rutas consistentes, status codes correctos, DTOs, ProblemDetails, OpenAPI, versionado si hay clientes.

## Datos

Indices, migraciones revisadas, queries proyectadas, transacciones claras, concurrencia donde aplique.

## Seguridad

Auth backend, policies, claims minimos, secrets fuera del repo, rate limiting en endpoints sensibles.

## Operabilidad

Logs estructurados, correlation id, health checks, metrics, traces, dashboard y alertas.

## Calidad

Tests para reglas, errores, permisos, DB crítica y flujos principales. CI ejecutando build/test.

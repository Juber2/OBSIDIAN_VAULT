# Proyecto Capstone API Empresarial

## Objetivo

Construir una API empresarial generica, sin depender de ningun proyecto real: usuarios, organizaciones, cursos, inscripciones, roles, auditoria y reportes.

## Arquitectura esperada

ASP.NET Core + EF Core + SQL + JWT + refresh token rotation + policies + ProblemDetails + OpenAPI + tests + Docker + observabilidad.

## Backlog por etapas

1. Modelo y CRUD.
2. Auth y roles.
3. EF Core con migraciones.
4. Testing.
5. Arquitectura por capas.
6. Observabilidad y Docker.
7. Performance y cache.

## Criterio de terminado

No basta que funcione local. Debe tener README, ADRs, tests, health checks, configuracion por ambiente y una explicacion de tradeoffs.

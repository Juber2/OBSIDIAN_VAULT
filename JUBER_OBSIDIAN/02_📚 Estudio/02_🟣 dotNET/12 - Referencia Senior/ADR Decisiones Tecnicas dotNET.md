# ADR Decisiones Tecnicas dotNET

## Formato recomendado

Contexto, decision, consecuencias, alternativas descartadas y fecha. Una pagina suele bastar.

## Cuándo escribir ADR

Arquitectura, autenticacion, base de datos, mensajeria, cache, estrategia de deploy, cambio de framework o boundaries.

## Ejemplo de titulo

ADR-003 - Usar refresh token rotation para sesiones web.

## Consecuencia

Un ADR bueno no solo dice lo elegido. Dice qué costo aceptaste y qué alternativa descartaste.

## App Service

Buen punto de partida para APIs .NET sin administrar Kubernetes.

## Azure SQL

Base relacional administrada. Vigila DTU/vCore, indices, locks y backups.

## Key Vault

Guarda secretos, certificates y keys. La app debe acceder con managed identity.

## Application Insights

## Ruta recomendada

1. C# y runtime: tipos, LINQ, async, nullability y CLR.
2. ASP.NET Core: pipeline, controllers, DI, validation, errores y OpenAPI.
3. EF Core y SQL: DbContext, migrations, queries, tracking y transacciones.
4. Seguridad: JWT, refresh token rotation, claims, policies y RBAC.
5. Arquitectura: Clean pragmatica, DDD tactico, CQRS y modular monolith.
6. Testing, performance, observabilidad, DevOps, Azure y mensajeria.
7. Senioridad: code review, diseno de APIs, migraciones legacy y proyecto final.

## Checkpoint senior

- [ ] Explico CLR, SDK, runtime, JIT, GC y assemblies.
- [ ] Construyo APIs ASP.NET Core con rutas, DI, validacion, ProblemDetails y OpenAPI.
- [ ] Uso EF Core entendiendo SQL, tracking, migrations, transacciones e indices.
- [ ] Diseño auth con JWT, refresh token rotation, claims y policies.
- [ ] Aplico arquitectura sin sobreingenieria y con dependencias correctas.
- [ ] Testeo dominio, servicios, API y base de datos real cuando importa.
- [ ] Mido performance con logs, traces, metrics y profiling antes de optimizar.
- [ ] Despliego con Docker/CI/CD/Azure y opero con observabilidad.

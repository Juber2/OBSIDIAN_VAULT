# Mapa de niveles dotNET

## Nivel 0

C#, POO, colecciones, excepciones, async básico, CLI y NuGet.

## Nivel 1

ASP.NET Core, DI, configuration, logging, controllers, Minimal APIs y EF Core básico.

## Nivel 2

JWT, Identity, policies, testing, migrations, transacciones y manejo global de errores.

## Nivel 3

Arquitectura, DDD táctico, CQRS, mensajería, performance, observabilidad y despliegue.

## Nivel 4

Diseño de sistemas .NET, code review, incidentes, migraciones legacy, modular monolith, microservicios y liderazgo técnico.

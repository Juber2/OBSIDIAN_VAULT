# Como estudiar dotNET con este vault

## Modelo de estudio

Cada modulo tiene un indice, notas tecnicas y practica. La idea no es memorizar APIs: es construir criterio para decidir, implementar, diagnosticar y explicar.

## Regla de avance

No marques una nota como terminada hasta escribir un ejemplo propio o aplicar el concepto en una API real.

## Proyecto paralelo recomendado

Mantén una API sandbox con usuarios, roles, cursos y auditoria. Ese dominio sirve para practicar controllers, EF Core, JWT, testing, caching, background jobs y arquitectura.

## Errores comunes

- Leer sin compilar codigo
- Copiar Clean Architecture sin entender dependencias

## Ruta recomendada

1. Domina C# y el runtime antes de saltar a frameworks.
2. Aprende ASP.NET Core con HTTP, DI, configuración, logs y validaciones.
3. Usa EF Core entendiendo SQL, tracking, transacciones e índices.
4. Agrega testing desde servicios pequeños hasta integración con base de datos.
5. Estudia arquitectura cuando ya puedas construir una API completa.
6. Cierra cada bloque con proyecto, retrospectiva y checklist.

## Checkpoint senior

- [ ] Puedo explicar CLR, IL, GC, JIT, assemblies y runtime.
- [ ] Puedo construir APIs limpias con ASP.NET Core, validación, errores y OpenAPI.
- [ ] Puedo usar EF Core sin caer en N+1, tracking innecesario o migraciones peligrosas.
- [ ] Puedo aplicar seguridad con JWT, Identity, OAuth2/OIDC, roles y policies.
- [ ] Puedo testear dominio, servicios, controllers e integración.
- [ ] Puedo dockerizar, observar, medir y diagnosticar una app .NET.
- [ ] Puedo diseñar soluciones con Clean Architecture, DDD, CQRS o modular monolith.
- [ ] Puedo revisar código y detectar riesgos de seguridad, performance y mantenibilidad.

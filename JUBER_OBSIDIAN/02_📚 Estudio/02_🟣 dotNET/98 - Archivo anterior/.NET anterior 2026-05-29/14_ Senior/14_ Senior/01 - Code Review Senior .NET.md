# Code Review Senior .NET

Un buen review prioriza riesgos: bugs, seguridad, performance, tests y mantenibilidad.

## Revisar

- Validaciones.
- Autorización.
- Transacciones.
- Queries EF.
- Errores HTTP.
- Tests.
- Logs.

## Checklist

- [ ] Comento riesgos, no gustos personales.
- [ ] Doy alternativa concreta.
- [ ] Reviso impacto en producción.
- [ ] Diferencio bloqueante de sugerencia.

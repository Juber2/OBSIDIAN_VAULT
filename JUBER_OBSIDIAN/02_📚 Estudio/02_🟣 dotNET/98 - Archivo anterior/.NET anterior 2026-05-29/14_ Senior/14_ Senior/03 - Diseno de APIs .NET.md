# Diseño de APIs .NET

Una API senior es consistente, versionable y segura.

## Reglas

- Rutas claras.
- Status codes correctos.
- DTOs explícitos.
- ProblemDetails.
- OpenAPI actualizado.
- Paginación.
- Versionado si hay consumidores externos.

## Checklist

- [ ] No expongo entidades EF.
- [ ] Los errores son consistentes.
- [ ] Uso contratos estables.
- [ ] Documento breaking changes.

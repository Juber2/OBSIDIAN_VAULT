## Concepto

Es el contrato de como la aplicación interactua con datos, dentro puede haber repository, querys y etc, todo lo que interactue con datos

# Repository

Va todo lo que devuelva siempre una entidad que se usara para un update o delete

# Querys

va todo lo que retorna un dto por ejemplo reportes

# Command

va solo la intencion que se desea hacer a la base de datos, como insert, update, delete

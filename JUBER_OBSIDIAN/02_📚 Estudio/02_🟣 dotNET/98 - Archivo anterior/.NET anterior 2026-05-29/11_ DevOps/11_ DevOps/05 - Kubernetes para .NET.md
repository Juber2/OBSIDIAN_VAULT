# Kubernetes para .NET

Kubernetes ejecuta contenedores con despliegue, escalado y health checks.

## Debes configurar

- Deployment.
- Service.
- ConfigMap.
- Secret.
- Readiness/liveness probes.
- Requests/limits.

## Checklist

- [ ] La app responde `/health`.
- [ ] Uso variables de entorno.
- [ ] Defino límites de recursos.
- [ ] Manejo graceful shutdown.

# dotnet CLI, Build y Publish

La CLI permite trabajar sin depender del IDE.

```bash
dotnet restore
dotnet build
dotnet test
dotnet publish -c Release -o ./publish
```

## Checklist

- [ ] Sé restaurar paquetes.
- [ ] Compilo en Release.
- [ ] Ejecuto tests por terminal.
- [ ] Publico artefactos reproducibles.

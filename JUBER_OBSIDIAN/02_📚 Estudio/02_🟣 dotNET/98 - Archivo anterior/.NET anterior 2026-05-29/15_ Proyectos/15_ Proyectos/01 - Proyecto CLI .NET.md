# Proyecto CLI .NET

## Objetivo

Crear una app de consola para gestionar tareas.

## Requisitos

- Crear tarea.
- Listar tareas.
- Completar tarea.
- Guardar en JSON.
- Tests de lógica.

## Checklist

- [ ] Ejecuta con `dotnet run`.
- [ ] Tiene separación entre consola y dominio.
- [ ] Maneja errores.
- [ ] Tiene README.

# Proyecto Microservicios .NET

## Objetivo

Construir un sistema distribuido pequeño con servicios .NET.

## Debe incluir

- API Gateway con YARP.
- Servicios independientes.
- RabbitMQ/Azure Service Bus.
- Outbox.
- OpenTelemetry.
- Docker Compose.
- CI/CD.

## Checklist

- [ ] Servicios con límites claros.
- [ ] Mensajes versionables.
- [ ] Observabilidad completa.
- [ ] Resiliencia ante fallos.

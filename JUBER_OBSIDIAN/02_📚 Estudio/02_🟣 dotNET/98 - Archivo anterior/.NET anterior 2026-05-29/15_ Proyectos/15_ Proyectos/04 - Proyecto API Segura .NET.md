# Proyecto API Segura .NET

## Objetivo

Crear autenticación y autorización completa.

## Requisitos

- Registro/login.
- JWT.
- Roles/policies.
- Refresh token opcional.
- Protección por recurso.
- Tests de auth.

## Checklist

- [ ] Passwords hasheados.
- [ ] Tokens expiran.
- [ ] Policies aplicadas.
- [ ] Usuarios no acceden datos ajenos.
